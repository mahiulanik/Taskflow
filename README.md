# TaskFlow

A full-stack task management application built with React, Vite,
Node.js, Express and MongoDB.

## Features

- JWT Authentication
- OTP Password Reset
- Task CRUD
- Protected Routes
- Helmet, HPP, Rate Limiting

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js, MongoDB
